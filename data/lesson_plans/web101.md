## Tuần 1: Giới thiệu HTML cơ bản

### Khái niệm
Cấu trúc thẻ HTML, thẻ text (p, h1-h6), danh sách (ul, ol), chèn ảnh và liên kết (img, a).

### Bài tập
Tạo một trang CV cá nhân bằng HTML.

## Tuần 2: CSS cơ bản & Định dạng giao diện

### Khái niệm
Selector, Box Model (margin, padding, border), màu sắc, font chữ.

### Bài tập
Trang trí trang CV của Tuần 1 bằng CSS.

## Tuần 3: JavaScript căn bản

### Khái niệm
Biến (let, const), kiểu dữ liệu, hàm (function), câu lệnh điều kiện if-else.

### Bài tập
Viết script tính tổng 2 số.
